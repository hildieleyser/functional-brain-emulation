Data Pipeline

1
Sensors
10 hardware devices generate raw neural, ocular, muscular, kinematic, and audio/video signals via proprietary SDKs and protocols.
2
Bridge Scripts
Python scripts (*_lsl.py) translate each device SDK into LSL outlets. Running on Windows 11 with Python 3.11. Located in C:\Users\chris\LSL_Tools\.
3
LSL Transport
Lab Streaming Layer unifies all streams with sub-millisecond network clock synchronization. pylsl 1.18.1. Up to 15 concurrent streams.
4
Recording
LabRecorder captures all active LSL streams to .xdf files with BIDS-compliant naming. Stored in Documents\CurrentStudy\.
5
Visualization
Real-time PyQt5 dashboards (lab + mobile). Offline Three.js 3D demo. Cinematic video exports via OpenCV.
